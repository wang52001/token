# 收款 SOP（兑换码模式）

客户付款到成交的完整流程，零平台费用、钱直进你口袋。

## 客户侧流程（你发给客户的说明）

1. 打开 `https://newapi.jdhsf.top`（上线前内测用 `http://192.168.31.93:3001`）注册账号（只需用户名+密码）
2. 微信/支付宝转账给你（附言写自己的**用户名**）
3. 收到你发的兑换码后，在「个人中心 → 兑换」输入兑换码，额度即刻到账
4. 「令牌」页自己创建 API key（无限额度即可，按账户余额扣）
5. 按《客户接入指南》配置客户端，开始使用

## 你侧流程（每笔 30 秒）

**本地内测期**（数据库在本机）：

```bash
# 1. 客户转账到账后，按金额生成兑换码
python3 /Users/wjw/Desktop/token/new-api/gen_code.py 50 --name 张三包月

# 2. 把输出的那串码发给客户（微信私聊）

# 3. 随时查码的状态（未使用/已使用）
python3 /Users/wjw/Desktop/token/new-api/gen_code.py --list
```

**上线后**（数据库在服务器上，gen_code.py 够不到）：管理后台 → 运营 → 兑换码 → 直接在线生成/查询，同样是 30 秒。

## 定价与成本（当前占位价，可调）

- 客户价：**$20 / 1M tokens**（输入输出同价；`options.ModelRatio=10`，想调价改这个数字即可，比例 1 = $2/1M）
- 你的成本：百炼上游约 ¥2-10 / 1M，毛利自己算
- 余额口径：$1 = 500,000 quota；$20/1M 意味着客户 $50 大约跑 2.5M tokens

## 已验证的客户全链路（2026-09-09 E2E）

注册 → 兑换 → 自建 key → 只见 33 个假名模型（零真实名泄露）→ 调用答假名 → 正常扣费 ✅

## 注意事项

- **客户注册即落 default 分组**（只见假名）；你自己和 cc-*/ali 令牌在 vip 分组（见全部 125 个模型）。不要在 default 组建真实模型的渠道
- 兑换码生成后**永不过期**（expired_time=0）；发错或要作废：`DELETE FROM redemptions WHERE key='...'`（或后台兑换管理页操作）
- 万相视频模型目前在 vip 组（客户不可见）；想卖视频再说一声，给它们单独开个组
- 合规门禁已确认（terms v1），重装/迁移后若兑换报"features are disabled"，用临时管理员走一遍 POST /api/option/payment_compliance 即可
- **分组用 new-api 原生组名**（default/vip/svip），自建组名（如 admin）会报"无权访问该分组"——除非同步加进 UserUsableGroups
