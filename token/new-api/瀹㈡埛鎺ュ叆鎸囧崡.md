# API 使用指南（客户版）

欢迎使用！按下面五步即可开始使用，全程自助。

## 第一步：注册账号

打开 `https://newapi.jdhsf.top`，用**用户名 + 密码**注册（无需邮箱验证，10 秒完成）。

> 内测期间地址为 `http://192.168.31.93:3001`（需与服务方在同一局域网）

## 第二步：充值

1. 微信/支付宝转账给服务方（**附言写上你的用户名**）
2. 服务方会发你一串**兑换码**
3. 登录后在「**个人中心 → 兑换**」输入兑换码，额度立即到账

## 第三步：创建 API Key

「**令牌**」页面 → 新建令牌 → 额度选**无限**（按账户余额扣费）→ 复制 `sk-` 开头的 key。

## 第四步：配置你的客户端

**Base URL 统一为 `https://newapi.jdhsf.top`**（内测期 `http://192.168.31.93:3001`）。

### Claude Code

```bash
export ANTHROPIC_AUTH_TOKEN="REDACTED"
export ANTHROPIC_BASE_URL="https://newapi.jdhsf.top"
export ANTHROPIC_MODEL="claude-fable-5-1"
```

### Codex CLI

```toml
# ~/.codex/config.toml
model_provider = "custom"
model = "gpt-6-astra"

[model_providers.custom]
name = "custom"
base_url = "https://newapi.jdhsf.top/v1"
wire_api = "responses"
experimental_bearer_token = "REDACTED"
```

### Gemini / CC Switch

Base URL 填 `https://newapi.jdhsf.top`，API Key 填你的 `sk-` key，模型选 `gemini-3.1-pro`、`gemini-3.8-flash` 等。

### 通用 API（curl）

```bash
curl https://newapi.jdhsf.top/v1/chat/completions \
  -H "Authorization: Bearer REDACTED" -H "Content-Type: application/json" \
  -d '{"model":"claude-fable-5-1","messages":[{"role":"user","content":"你好"}]}'
```

## 第五步：查用量、续费

- 「**个人中心**」随时查看余额和调用日志
- 余额不足时重复第二步即可（转账 → 领码 → 兑换）

## 可用模型

你的账号可以看到 **Claude 全系（Fable 5.1 / Opus 5 / Sonnet 5 / Haiku 4.5 等）、Gemini 全系（3.1 Pro / 3.8 Flash / 2.5 系）、GPT 全系（6 Astra / 5.6 Sol / 5.5 / 5.2 等）**，共 33 个，以「令牌 → 可用模型」列表为准。

## 常见问题

- **401 Invalid token**：key 复制不完整，或账户余额不足——先去个人中心看余额
- **403 模型不可用**：该模型不在你的套餐内，以可用模型列表为准
- **连不上**：确认地址是 `https://newapi.jdhsf.top`（内测期为局域网地址，换网络后失效属正常）
- **兑换码提示无效**：检查是否完整复制（32 位），仍不行联系服务方重发
